FAQ

Common questions

Do I need a business registration to use OpPay? +
No. OpPay has no KYC requirements for merchants. Set up an account with just an email, business name, and Bitcoin payout address. It's Bitcoin — borderless by design.
What happens if a customer doesn't pay within the session window? +
Sessions expire after 30 minutes by default (configurable via SESSION_EXPIRY_MINUTES). The session status changes to expired and a new session must be created for the next attempt.
Can I use OpPay with my existing Shopify or WooCommerce store? +
Yes. For Shopify, add the script tag via a custom liquid template and use the JavaScript API to create sessions when customers hit checkout. For WooCommerce, add a custom payment gateway plugin that calls the OpPay API server-side.
How do I handle refunds? +
Bitcoin transactions are irreversible — there are no automatic refunds. For standard payments you would manually send BTC back to the customer's wallet. For OpCredit payments, before escrow is released you can decline the release by not triggering the confirm endpoint, though the 14-day auto-release will still apply.
Is OpPay open source? +
Yes. The entire codebase — backend, dashboard, and SDK — is open source. You can self-host it for free, modify it, and audit every line of code. The Pro and Enterprise tiers offer managed hosting if you don't want to run your own infrastructure.
What currencies can I price products in? +
EUR, USD, GBP, JPY, CHF, AUD, and CAD — all supported. Pass currency: 'USD' when creating a session and the BTC equivalent is calculated live using CoinGecko with a 1-minute cache. The widget automatically formats prices in the customer's chosen currency.
